# 03 接口设计

## 1. 约定

| 项 | 约定 |
| --- | --- |
| 协议 | HTTP/1.1，REST 风格，JSON（`application/json;charset=UTF-8`） |
| 前缀 | `/api` |
| 方法 | 当前全部为查询接口（`GET`）与缓存清理（`DELETE`），无业务写接口 |
| 分页参数 | `page`（从 0 开始，默认 0）、`size`（默认见各接口） |
| 时间格式 | ISO-8601 字符串（如 `2026-06-12T23:35:25.389797`） |
| 空字段 | `spring.jackson.default-property-inclusion=non_null`，null 字段不输出 |
| 跨域 | `/api/**` 支持 CORS，来源由 `app.cors.allowed-origins` 控制 |

### 统一分页结构 `PageResult<T>`

```json
{
  "content": [ {} ],
  "page": 0,
  "size": 12,
  "totalElements": 8,
  "totalPages": 1,
  "first": true,
  "last": true
}
```

### 统一错误结构 `ApiError`

```json
{
  "timestamp": "2026-10-10T15:36:06.481828Z",
  "status": 404,
  "error": "Not Found",
  "message": "小说不存在：id=9999",
  "path": "/api/novels/9999"
}
```

| HTTP 状态 | 触发条件 |
| --- | --- |
| 404 | 业务对象不存在（`NotFoundException`）；请求路径无对应处理器或静态资源 |
| 400 | 参数缺失 / 类型不匹配 / 参数校验失败 / `IllegalArgumentException` |
| 500 | 其他未捕获异常（服务端已记录堆栈日志） |

## 2. 接口清单

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/home` | 首页聚合数据 |
| GET | `/api/categories` | 全部分类 |
| GET | `/api/categories/{id}` | 分类详情 |
| GET | `/api/categories/{id}/novels` | 分类书库（分页） |
| GET | `/api/novels` | 书籍列表，可按分类筛选 |
| GET | `/api/rank` | 排行榜 |
| GET | `/api/search` | 关键词检索 |
| GET | `/api/novels/{id}` | 书籍详情 |
| GET | `/api/novels/{id}/chapters` | 全部章节目录 |
| GET | `/api/novels/{id}/chapter-page` | 分页章节目录 |
| GET | `/api/novels/{id}/chapters/{no}` | 按章节号阅读 |
| GET | `/api/novels/chapters/{chapterId}` | 按章节 id 阅读 |
| GET | `/api/cache` | 缓存统计（运维） |
| DELETE | `/api/cache/{name}` | 清空指定缓存（运维） |

## 3. DTO 定义

### CategoryDto

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Long | 分类 id |
| name | String | 分类名 |
| description | String | 简介 |
| sortNo | Integer | 排序号 |

### NovelSummary

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id / title / author | Long / String / String | 基础信息 |
| description | String | 简介（含换行） |
| categoryId / categoryName | Long / String | 所属分类 |
| coverColor / coverMark | String / String | 封面渐变值 / 占位字符 |
| status / statusText | String / String | `ONGOING` / `FINISHED` 与中文文案 |
| tags | List&lt;String&gt; | 标签数组 |
| rating / viewCount / wordCount / chapterCount | Double / Long / Long / Integer | 评分与统计 |
| updatedAt | LocalDateTime | 最近更新 |

### NovelDetail

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| novel | NovelSummary | 书籍摘要 |
| firstChapter / lastChapter | ChapterItem | 首章 / 最新章（无章节时为 null） |
| chapters | List&lt;ChapterItem&gt; | 章节预览，默认 10 条 |
| related | List&lt;NovelSummary&gt; | 同类推荐，最多 6 条 |

### ChapterItem

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id / no / title / wordCount | Long / Integer / String / Integer | — |
| createdAt | LocalDateTime | 章节创建时间 |

### ChapterDetail

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id / no / title / wordCount | Long / Integer / String / Integer | — |
| paragraphs | List&lt;String&gt; | 按 `\n` 切分并去除空行后的正文段落 |
| novelId / novelTitle | Long / String | 所属书籍 |
| prevNo / nextNo | Integer | 上下章序号，无则为 null |

### HomeVo

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| totalNovels | long | 全站书籍总数 |
| categories | List&lt;CategoryDto&gt; | 分类导航 |
| recommends / hot / finished | List&lt;NovelSummary&gt; | 精选（按评分）/ 热门（按点击）/ 完本佳作 |
| latest | List&lt;NovelUpdate&gt; | 最近更新，`{ novel, latestChapter }` |

## 4. 接口详情与示例

### GET /api/home

首页一次性聚合，减少前端请求数。

```json
{
  "totalNovels": 8,
  "categories": [{ "id": 1, "name": "玄幻奇幻", "description": "御剑乘风，问长生何处", "sortNo": 1 }],
  "recommends": [{ "id": 1, "title": "登云帖", "author": "青冥", "rating": 9.2 }],
  "hot": [{ "id": 5, "title": "沉默的第三人", "viewCount": 3245871 }],
  "finished": [{ "id": 2, "title": "长夜拾星", "statusText": "完结" }],
  "latest": [{ "novel": { "id": 1 }, "latestChapter": { "id": 16, "no": 16, "title": "第十六章 登云" } }]
}
```

### GET /api/categories/{id}/novels

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| sort | hot | `hot` 按点击排序（`findByCategoryOrderByViewCountDesc`），`update` 按更新时间排序 |
| page / size | 0 / 12 | 分页 |

### GET /api/novels

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| categoryId | 空 | 传入时等价于分类书库，否则走全站排序列表 |
| sort | hot | `hot` / `rating` 映射排行榜查询，其余按人气处理 |
| page / size | 0 / 12 | 分页 |

### GET /api/rank

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| type | hot | `hot` 按 `viewCount` 降序；`rating` 按 `rating, viewCount` 降序 |
| page / size | 0 / 20 | 分页 |

### GET /api/search

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| q | 空 | 关键词为空时返回空分页；否则匹配书名 / 作者 / 标签（均忽略大小写） |
| page / size | 0 / 12 | 分页 |

对应 JPQL：

```sql
select n from Novel n
where lower(n.title)  like lower(concat('%', :keyword, '%'))
   or lower(n.author) like lower(concat('%', :keyword, '%'))
   or lower(n.tags)   like lower(concat('%', :keyword, '%'))
```

### GET /api/novels/{id}

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| chapterPreview | 10 | 详情内嵌章节预览条数 |

> 副作用：该接口会自增书籍点击数并失效 `novel-detail` 缓存。

### GET /api/novels/{id}/chapters

返回全书章节数组（不分页）。章节较多的书建议改用 `/chapter-page`。

### GET /api/novels/{id}/chapter-page

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| page / size | 0 / 50 | 在已缓存的完整目录上做内存分页，返回 `PageResult<ChapterItem>` |

### GET /api/novels/{id}/chapters/{no} 与 /api/novels/chapters/{chapterId}

返回 `ChapterDetail`，含 `paragraphs`、`prevNo`、`nextNo`。前端可直接据此渲染正文与上下章按钮。

```json
{
  "id": 1, "no": 1, "title": "第一章 山门前的雪", "wordCount": 241,
  "paragraphs": ["第一章 山门前的雪", "青石阶上一层薄霜……"],
  "novelId": 1, "novelTitle": "登云帖", "prevNo": null, "nextNo": 2
}
```

### GET /api/cache

```json
{
  "type": "com.novel.browse.cache.RocksDbCacheManager",
  "cacheNames": ["novel-chapter", "novel-chapter-list", "novel-chapter-no", "novel-detail", "novel-home-list"],
  "ttlMillis": 600000,
  "cleanOnStart": true,
  "caches": [{ "name": "novel-home-list", "hits": 12, "misses": 5, "puts": 5, "evictions": 0, "size": 5 }]
}
```

### DELETE /api/cache/{name}

清空指定缓存，返回 `{ "name": "novel-detail", "cleared": true }`；缓存名不存在返回 404。

## 5. 前端对接建议

1. 首屏：`GET /api/home` 一次拿到分类与各类书单；
2. 列表页：优先 `/api/categories/{id}/novels` 与 `/api/rank`，统一消费 `PageResult`；
3. 详情页：`/api/novels/{id}` + `/api/novels/{id}/chapter-page`；
4. 阅读页：`/api/novels/{id}/chapters/{no}`，按 `prevNo / nextNo` 翻章；
5. 错误统一依据 `status` 与 `error` 字段处理，避免依赖 `message` 文案。
